LifeOS is a privately operated productivity app for Mac, Windows and the web, with optional Google Drive synchronization.

About LifeOS

Organize Markdown notes in folders, manage tasks in separate lists, and create process-flow diagrams. The desktop app works locally; connecting a Google account lets its owner synchronize their workspace between their own installations.

Google Drive access uses the drive.file permission, limited to files created or explicitly opened with LifeOS. Connecting does not make the workspace public.

The current preview saves a local JSON workspace and generates portable Markdown, attachment, and Flow JSON copies. Synchronization uses Drive revision files. External edits to the generated copies are not automatically imported.

This website contains application information only. It does not offer workspace access, downloads, public registration, or access to the owner's data.

Privacy policy

Updated October 27, 2026 · Desktop and web preview

Google information accessed

LifeOS requests the Google Drive drive.file permission to create and synchronize its workspace files and retrieve files accessible under that permission. It also retrieves the connected account's email address and Drive permission identifier to display the account and prevent mixing workspaces from different accounts.

How information is used and stored

Notes, tasks, flow diagrams, folders, templates, and attachments are saved on the device. When Google Drive is connected, workspace revisions are uploaded to the connected account's LifeOS folder in Google Drive. Other authorized installations for that account download those revisions to synchronize changes.

The desktop app stores the OAuth client configuration and refresh token locally using operating-system encryption. Working workspace files and Drive revision contents are not encrypted by LifeOS itself; device protection and Google Drive's security controls apply. The client secret and refresh token are not included in installers or uploaded as workspace data.

Web app authorization and notifications

The web app keeps a per-device connection in browser storage. A private Cloudflare Worker renews Google access using a refresh token encrypted with AES-GCM and a server-only encryption key. The private database stores the encrypted token, account email, hashed device session and expiry. Sessions expire after 90 days without renewal. Disconnect deletes that device session; revoking LifeOS in Google Account also prevents future renewal. Workspace contents sync directly with Google Drive and are not stored by the authorization service.

Optional web push stores device notification subscriptions, note identifiers and reminder schedules in the private Cloudflare database. Notifications contain generic review messages rather than note text or titles. Disabling push removes that device registration. Cloudflare and Google process service requests under their own policies. Published app code is public; your workspace and credentials are not included.

Sharing and other uses

The desktop synchronization implementation sends Google user data to Google Drive for the requested synchronization. It does not send that data to an advertising or analytics service, sell it, or use it to train AI models. This statement covers the desktop app, not separate services the owner may choose to use with exported files. LifeOS's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and controls

Disconnecting Google Drive stops that installation's synchronization and removes its stored refresh token. It does not delete local workspace files or existing Drive revisions. The current preview retains full revision history without automatic pruning. Copies on other devices and exported backups remain until their owner removes them.

The owner can revoke LifeOS access through their Google Account and manage or delete the LifeOS files through Google Drive. Deleting individual revision files while sync is active can prevent history from loading; disconnect installations before deliberately removing the whole cloud workspace.

The current application is for its owner's personal use. The OAuth consent screen identifies the owner's support contact.

Reference: Google API Services User Data Policy. This static information site is hosted by GitHub Pages; GitHub processes website requests under its privacy statement. The site itself has no forms, analytics scripts, cookies set by application code, or Google sign-in.

Personal-use terms

Updated October 26, 2026

LifeOS is a privately operated desktop application intended for its owner's own notes, tasks, and flow diagrams. This information page does not offer a public hosted workspace or registration service.

Google Drive synchronization is optional and requires the account owner's authorization. Google services remain governed by Google's applicable terms. The owner retains control of their workspace and is responsible for deciding which devices and Google account to connect.

This is a development preview. Backups are recommended. Windows runtime behavior, simultaneous cross-device editing, large attachments, and recovery from conflicting edits require further verification. There is no promise of uninterrupted synchronization or permanent authorization.

No fee is charged by this personal application. Third-party storage quotas and service terms apply independently. These terms do not grant rights to third-party libraries or change their licenses.
